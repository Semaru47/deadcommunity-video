# DeadVideo

> ◆ DeadCommunity product card — **no source code · no API keys**.

### ◆ Role

**In-browser video editor** — lightweight cuts on `video.deadcommunity.com`, and the **DeadVideo Pro NLE** timeline editor on `edit.deadcommunity.com` (forum-gated, CapCut-style timeline).

### ◆ Live

↳ **[https://video.deadcommunity.com](https://video.deadcommunity.com)** — lightweight editor  
↳ **[https://edit.deadcommunity.com](https://edit.deadcommunity.com)** — DeadVideo Pro (NLE)

### ◆ What it does

▸ Client-side editing for quick jobs (classic DeadVideo)  
▸ Full timeline NLE: media, sounds, text, stickers, effects, animations, captions  
▸ Multi-language UI (EN / TR / JA / ZH)  
▸ Forum member soft-gate for Pro  
▸ Part of the DC tool suite

### ◆ Highlights

○ Sibling to DeadSound  
○ Pro editor at `edit.deadcommunity.com`  
○ Live and containerized

### ◆ Who it’s for

▸ Creators needing quick browser edits  
▸ Forum members using the Pro timeline

### ◆ Stack (high level)

`Next.js` · `Web app` · `Docker` · `Nginx` · `Cloudflare Tunnel`
